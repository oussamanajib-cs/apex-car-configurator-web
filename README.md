
# Apex Car Configurator 🚗

A modern web application that allows users to customize a car by selecting different options such as color, wheels, and interior, with real-time price updates.

---

## ✨ Features

- 🎨 Choose car color with live preview  
- 🛞 Select wheels and design options  
- 🪑 Customize interior styles  
- 💰 Dynamic price calculation  
- 📱 Fully responsive design (mobile-friendly)  
- 🧾 Summary of selected configuration
